📚 Library Management System

A simple console-based Library Management System built in Java that allows users to manage books through a menu-driven interface.


🗂️ Project Structure

LibraryManagementSystem/
│
├── Main.java       # Entry point; handles user menu and input
├── Library.java    # Core library logic (add, remove, search)
└── Book.java       # Book model class (title, author, ISBN)


✨ Features


➕ Add a Book — Add a new book with title, author, and ISBN
❌ Remove a Book — Remove a book using its ISBN
🔍 Search by Title — Find books matching a given title
👤 Search by Author — Find all books by a specific author
🚪 Exit — Gracefully exit the application
